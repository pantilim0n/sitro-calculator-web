# Домен, резервная копия и перенос сайта СИТРО

Сайт не привязан к Vercel по устройству интерфейса. Статические страницы, изображения и данные можно разместить на другом сервере. Для полной работы нужны серверные обработчики из папки `api`, переменные окружения и доступ к репозиторию GitHub, потому что админка сейчас сохраняет изменения через GitHub API.

## Подключение собственного домена

1. Выбрать и зарегистрировать домен.
2. Добавить домен в панели текущего хостинга.
3. Указать DNS-записи, которые покажет хостинг.
4. После выпуска HTTPS-сертификата заменить адрес Vercel в canonical, sitemap и структурированных данных.
5. Проверить главную страницу, админку, калькулятор, MakerWorld, загрузку фотографий и отправку заявки.

## Перенос на российский сервер

Для независимости от Vercel нужен российский VPS с Node.js 22 или совместимой средой для обработчиков API. Статические файлы можно отдавать через Nginx. На сервер переносятся обработчики `api/order.js`, `api/makerworld.js` и `api/admin-portfolio.js`.

Если требуется работа без GitHub, админку надо перевести с GitHub API на базу данных или файловое хранилище российского сервера. До такой переработки GitHub остаётся источником данных и истории.

### Что обязательно сделать перед переключением домена

1. Поднять сервер с Node.js 22, Nginx и HTTPS.
2. Перенести все обработчики из `api` и закрытые переменные окружения. Секреты нельзя помещать в Git или открытые файлы сайта.
3. Перевести данные админки с GitHub API в базу данных или постоянное файловое хранилище, если сайт должен работать без GitHub.
4. Добавить очередь неотправленных уведомлений и повторные попытки для Telegram и MAX. Сохранение заявки должно оставаться главным действием, а сбой мессенджера не должен терять заказ.
5. Настроить автоматические резервные копии базы, содержимого админки, загруженных файлов и папки заявок на Яндекс Диске.
6. Проверить исходящие соединения сервера с `cloud-api.yandex.net`, `api.telegram.org`, `platform-api2.max.ru` и API MakerWorld.
7. Провести сквозные проверки двух сценариев: заказ с загруженным STL/3MF и заказ по ссылке MakerWorld. Для каждого проверить сохранение заявки и доставку уведомлений.
8. Не отключать GitHub и Vercel до успешной проверки российского сервера. Затем переключить DNS и сохранить архив последней рабочей версии.

Этот список является обязательным планом переноса. Его нужно проверить полностью, даже если перенос выполняется в новом чате.

## Резервная копия

- Скачать резервную копию из админки.
- Создать архив всей локальной папки проекта.
- Убедиться, что все изменения отправлены в `origin/main`.
- Хранить копию архива отдельно от рабочего компьютера.
